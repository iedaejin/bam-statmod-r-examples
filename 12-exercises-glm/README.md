# Session 12 — GLM Exercises

Statistical Modelling (BAM), IE University, Spring 2027 · Prof. Dae-Jin Lee

## By the end of this session you should be able to

1. **Choose** a random component, a link and an offset for a described response.
2. **Derive** the log-likelihood, score and Fisher information of a binomial GLM.
3. **Interpret** coefficients as odds ratios, rate ratios and derived quantities (LD50).
4. **Compute** LR tests, AIC and $\hat\phi$ from printed output, without software.
5. **Diagnose** a fitted count model and **justify** a remedy.

## How to follow this session

1. **Before class:** read the required texts in [readings.md](readings.md).
2. **In class:** we work the problems in [exercises.md](exercises.md) in groups, by hand first. The R scripts that check the answers are published here after the session.
