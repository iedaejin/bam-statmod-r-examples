# Session 30 — Group-Project Presentations

Statistical Modelling (BAM), IE University, Spring 2027 · Prof. Dae-Jin Lee

## By the end of this session you should be able to

1. **Present** a statistical analysis to a technical audience in 10 minutes.
2. **Communicate** estimates together with their uncertainty and the diagnostics behind them.
3. **Defend** the choice and comparison of models in a Q&A.
4. **Evaluate** another group's analysis with specific, constructive feedback.
