# Session 14 — Midterm Exam

Statistical Modelling (BAM), IE University, Spring 2027 · Prof. Dae-Jin Lee

## What the exam assesses

1. **Derive** likelihood quantities (score, information, MLE) and least-squares results by hand.
2. **Compute** standard errors, confidence intervals and Wald, score, LR, $t$ and $F$ statistics.
3. **Interpret** printed `lm()` and `glm()` output in context, with units.
4. **Compare** models with tests and information criteria.
5. **Diagnose** model problems from residual and influence plots.
