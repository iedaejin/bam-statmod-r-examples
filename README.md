# Statistical Modelling — R examples

Session-by-session R examples for Statistical Modelling, Bachelor in Applied Mathematics (BAM), IE University.

The GitHub Pages site is the catalog: each session is one folder with the scripts and the data they read.

Datasets come from R packages (datasets, MASS, faraway, lme4, nlme, survival) under their own licences.
