# Session 32 — Final Exam

Statistical Modelling (BAM), IE University, Spring 2027 · Prof. Dae-Jin Lee

## What the exam assesses

1. **Choose** an appropriate model for a question and a data structure.
2. **Derive** key results by hand (likelihoods, penalized least squares, BLUPs, Kaplan–Meier).
3. **Fit** the models in R and **diagnose** their assumptions.
4. **Interpret** estimates, smooths, variance components and hazard ratios in context.
5. **Compare** models with tests and information criteria, including boundary cases.
